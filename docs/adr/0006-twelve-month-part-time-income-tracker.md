# ADR 0006: สถาปัตยกรรมระบบบันทึกรายได้ 12 เดือนสำหรับพาร์ทไทม์และฟรีแลนซ์ (12-Month Income Tracker)

## สถานะ (Status)
อนุมัติแล้ว (Accepted)

## บริบท (Context)
ผู้ใช้งานกลุ่มคนทำงานพาร์ทไทม์ (Part-time), ฟรีแลนซ์ (Freelance), และผู้มีรายได้ไม่คงที่ในแต่ละเดือน พบอุปสรรคสำคัญในการวางแผนภาษี:
1. **รายได้ผันผวนทุกเดือน:** ไม่สามารถใช้ฟังก์ชัน "รายได้ต่อเดือน x12" ในหน้าคำนวณปกติได้ เพราะแต่ละเดือนได้เงินไม่เท่ากัน
2. **ภาษีหัก ณ ที่จ่ายสะสมกระจัดกระจาย:** มักถูกผู้ว่าจ้างหัก 3% ไว้เรื่อยๆ โดยไม่มีที่รวบรวม ทำให้ปลายปีไม่ทราบยอดรวมที่แท้จริง และพลาดสิทธิในการขอเงินคืนภาษี (Tax Refund)
3. **ความต้องการกรอกข้อมูลที่แตกต่างกัน:** บางคนมีประกันสังคม (ม.33 หรือ ม.40) บางคนไม่มี, บางคนโดนหัก 3% บางคนไม่โดน หากบังคับให้กรอกทุกช่องจะทำให้ฟอร์มรกและใช้งานยากบนมือถือ

## การตัดสินใจ (Decision)

### 1. หน้าเว็บและการนำทาง (Navigation & Route)
- สร้างหน้าใหม่แยกอิสระที่เส้นทาง `/monthly-tracker` พร้อมลิงก์ใน Sidebar เมนู **"📅 บันทึกรายได้ 12 เดือน"**
- รองรับการเลือกปีภาษี (Tax Year Dropdown) เช่น 2569 (2026), 2568 (2025)

### 2. การเลือกคอลัมน์แบบกำหนดเอง (Customizable Monthly Columns)
- ด้านบนของหน้ามีแถบตัวเลือกคอลัมน์ (Column Selector Pills) ให้ผู้ใช้ติ๊กเปิด/ปิดตามลักษณะงานของตนเอง:
  - `[✓] รายได้ของเดือน (Income)` *(บังคับแสดงเสมอ)*
  - `[ ] ภาษีหัก ณ ที่จ่าย (Withholding Tax)` *(เปิด/ปิดได้)*
  - `[ ] ประกันสังคม (Social Security)` *(เปิด/ปิดได้)*
  - `[ ] โน้ต/แหล่งที่มา (Note/Workplace)` *(เปิด/ปิดได้)*
- แต่ละเดือน (ม.ค. - ธ.ค.) จะแสดงเฉพาะช่องที่ผู้ใช้เปิดใช้งาน ช่วยลด Cognitive Load และทำให้เลย์เอาต์บนมือถือกระชับ สบายตา

### 3. ฟังก์ชันอำนวยความสะดวกอัจฉริยะ (Smart UX Helpers)
- ปุ่ม **"หัก 3% อัตโนมัติ"** ประจำแถวหรือสำหรับทุกเดือน เพื่อคำนวณภาษีหัก ณ ที่จ่ายจากยอดรายได้ทันที
- ปุ่ม **"คัดลอกไปยังเดือนถัดไป"** สำหรับเดือนที่ได้ค่าจ้างเท่าเดิม
- แถบสรุปผลลัพธ์สด (Live Summary Bar) ด้านบน/ด้านล่าง:
  - รายได้รวมทั้งปี, ภาษีหักสะสมทั้งปี, ประกันสังคมรวมทั้งปี
  - **Estimated Refund Callout:** แจ้งเตือนสิทธิขอคืนภาษีเบื้องต้น (เช่น *"🎉 คุณมีโอกาสได้รับเงินคืนภาษีสะสมสูงสุด +X,XXX บาท"*)
- ปุ่ม **"🚀 ส่งยอดไปคำนวณภาษีประจำปี"** นำทางไปยัง `/calculator` พร้อมส่งยอดรวมไปกรอกในฟอร์มคำนวณอัตโนมัติ

### 4. การจัดเก็บข้อมูลในฐานข้อมูล (Database Persistence)
- สร้างตาราง `monthly_income_records` ใน PostgreSQL:
  ```sql
  CREATE TABLE IF NOT EXISTS monthly_income_records (
      id SERIAL PRIMARY KEY,
      user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
      tax_year INTEGER NOT NULL,
      month INTEGER NOT NULL CHECK (month BETWEEN 1 AND 12),
      income DECIMAL(12,2) DEFAULT 0,
      withholding_tax DECIMAL(12,2) DEFAULT 0,
      social_security DECIMAL(12,2) DEFAULT 0,
      note TEXT DEFAULT '',
      created_at TIMESTAMP DEFAULT NOW(),
      updated_at TIMESTAMP DEFAULT NOW(),
      UNIQUE(user_id, tax_year, month)
  );
  ```
- มี API รองรับ:
  - `GET /api/monthly-tracker?year=2026`: ดึงข้อมูล 12 เดือนของปีนั้น
  - `POST /api/monthly-tracker`: บันทึกข้อมูลแบบ Bulk Upsert

## ผลลัพธ์ (Consequences)
- คนทำงานพาร์ทไทม์และฟรีแลนซ์สามารถเข้ามาจดรายได้ได้จริงในทุกๆ สิ้นเดือนตลอดทั้งปี
- เลย์เอาต์บนมือถือมีความคลีน ไม่รก ไม่เกิดปัญหาจมกองฟอร์ม (Form Fatigue)
- เชื่อมต่อกับระบบ Tax Engine เดิมได้อย่างไร้รอยต่อ โดยไม่ต้องเปลี่ยนโครงสร้างโมเดลภาษีหลัก
