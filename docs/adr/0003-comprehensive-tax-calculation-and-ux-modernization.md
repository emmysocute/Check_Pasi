# ADR 0003: การยกระดับความแม่นยำระบบภาษี (TaxMe), ระบบหัก ณ ที่จ่าย และ Modern UX

## สถานะ (Status)
อนุมัติแล้ว (Accepted)

## บริบท (Context)
ระบบ Check Pasi (TaxMe) มีแกนการคำนวณภาษีเงินได้บุคคลธรรมดาขั้นบันไดและเก็บบันทึกประวัติเบื้องต้นแล้ว แต่ยังมีช่องว่างเมื่อเทียบกับการยื่นแบบแสดงรายการภาษีจริง (ภ.ง.ด. 90/91):
1. **ขาดระบบภาษีหัก ณ ที่จ่าย (Withholding Tax):** ผู้เสียภาษีส่วนใหญ่ถูกหักภาษี ณ ที่จ่ายตามใบ 50 ทวิไประหว่างปี แต่ระบบเดิมยังไม่รองรับ ทำให้ผู้ใช้ไม่ทราบสถานะสุทธิว่าแท้จริงแล้วตนเองต้อง **"ชำระเพิ่ม"** หรือ **"มีสิทธิขอคืนภาษี (Tax Refund)"**
2. **รายการลดหย่อนยังไม่ครอบคลุมชีวิตจริง:** ขาดรายการลดหย่อนสำคัญ เช่น ดอกเบี้ยเงินกู้ยืมเพื่อซื้อที่อยู่อาศัย (สูงสุด 100,000 บาท), ค่าลดหย่อนบิดามารดา (คนละ 30,000 บาท) และเงินบริจาค
3. **ขาดการคำนวณภาษีวิธีที่ 2 (เหมา 0.5%):** ตามประมวลรัษฎากร ม.48(2) หากมีเงินได้ที่ไม่ใช่เงินเดือนเกิน 120,000 บาท/ปี ต้องคำนวณเปรียบเทียบกับวิธีเหมา 0.5%
4. **การแสดงผลยังไม่ให้ Insight เชิงลึก:** ผู้ใช้เห็นเฉพาะยอดภาษีรวมก้อนเดียว ไม่สามารถดูแจกแจงตามขั้นบันได (Tax Bracket Breakdown) ว่าเงินได้สุทธิตกอยู่ในขั้นใดบ้าง
5. **ประสบการณ์ผู้ใช้ (UX):** ยังใช้ `window.alert()` แบบ Browser Popup เดิม ซึ่งขัดกับดีไซน์โมเดิร์นของระบบ

## การตัดสินใจ (Decision)

### 1. ระบบภาษีหัก ณ ที่จ่ายและการคำนวณเงินคืนภาษี (Withholding Tax & Tax Refund)
- เพิ่มช่องกรอก **ภาษีหัก ณ ที่จ่ายสะสม (Withholding Tax)** ในส่วนข้อมูลรายได้
- คำนวณยอดสุทธิ: $\text{Net Balance} = \text{ภาษีที่คำนวณได้} - \text{ภาษีหัก ณ ที่จ่าย}$
- ออกแบบ UI การแสดงผลในการ์ดสรุปผล (`ResultPanel`):
  - กรณีภาษีหัก ณ ที่จ่าย $>$ ภาษีที่คำนวณได้: แสดงกล่อง **"ยอดเงินคืนภาษีที่จะได้รับ (Tax Refund)"** สีเขียวสดใส (`var(--green-500)`)
  - กรณีภาษีที่คำนวณได้ $>$ ภาษีหัก ณ ที่จ่าย: แสดงกล่อง **"ภาษีที่ต้องชำระเพิ่มเติม"** สีส้ม/แดง พร้อมแจกแจงยอดสุทธิอย่างชัดเจน

### 2. ขยายรายการลดหย่อนภาษีมาตรฐานสรรพากร (Extended Deductions)
- **ดอกเบี้ยเงินกู้ยืมเพื่อซื้อที่อยู่อาศัย (Home Loan Interest):** หักได้ตามจริงสูงสุดไม่เกิน 100,000 บาท
- **ค่าลดหย่อนบิดามารดา (Parent Allowance):** หักคนละ 30,000 บาท (รองรับเลือกบิดา/มารดาของผู้มีเงินได้และคู่สมรส)
- **เงินบริจาค (Donations):** บริจาคเพื่อการศึกษา/กีฬา/รพ.รัฐ (ลดหย่อน 2 เท่า) และบริจาคทั่วไป รวมกันไม่เกิน 10% ของเงินได้หลังหักค่าใช้จ่ายและค่าลดหย่อน

### 3. ระบบคำนวณภาษีวิธีที่ 2 (Flat Rate 0.5% - ม.48(2))
- ตรวจสอบอัตโนมัติ: หาก `freelanceIncome > 120,000` บาท ให้คำนวณ $\text{ภาษีวิธีที่ 2} = \text{freelanceIncome} \times 0.005$
- หากภาษีวิธีที่ 2 เกิน 5,000 บาท และมีมูลค่ามากกว่าภาษีวิธีขั้นบันได (วิธีที่ 1) ระบบจะเลือกใช้ภาษีวิธีที่ 2 พร้อมแสดง Badge แจ้งเตือนผู้ใช้

### 4. การแจกแจงภาษีตามขั้นบันได (Tax Bracket Breakdown)
- เพิ่มส่วนแสดงผลแจกแจงขั้นบันไดภาษี 8 ขั้นใน `ResultPanel` พร้อมปุ่มกดคลี่ดู/พับเก็บ (Collapsible Accordion)
- ไฮไลต์ **ฐานภาษีสูงสุดของผู้ใช้ (Marginal Tax Bracket)** เพื่อให้ผู้ใช้วางแผนลดหย่อนภาษีเพิ่มเติมได้อย่างแม่นยำ

### 5. การปรับปรุงความทันสมัยของ UX (Modern Toast UI & Code Cleanup)
- ติดตั้งระบบ **Toast Notification** เพื่อแจ้งเตือนผลการบันทึกข้อมูลสำเร็จ/ผิดพลาด แทนที่ `window.alert()`
- เก็บกวาด Lint warnings และแยกตรรกะการคำนวณภาษีให้เป็นระเบียบ

### 6. การจัดเก็บข้อมูลและ Schema Migration
- ขยายคอลัมน์ในตาราง `tax_records` ผ่าน Non-destructive Auto-migrations:
  - `withholding_tax`, `home_loan_interest`, `parent_allowance`, `donation`, `tax_method`

## ผลลัพธ์ (Consequences)
- ระบบ Check Pasi ก้าวขึ้นสู่เครื่องมือคำนวณและวางแผนภาษีที่มีความแม่นยำระดับมาตรฐานสรรพากร 100%
- ผู้ใช้ได้รับประโยชน์สูงสุดจากการทราบยอดเงินคืนภาษีจริงและเห็นภาพโครงสร้างภาษีของตนเองอย่างโปร่งใส
- สถาปัตยกรรมโค้ดมีความสะอาด มั่นคง และรองรับการขยายตัวในอนาคตได้อย่างมีประสิทธิภาพ
