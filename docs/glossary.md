# พจนานุกรมคำศัพท์โดเมน (Domain Glossary)

| คำศัพท์ (Term) | ความหมายและบทบาทในระบบ (Definition & Responsibility) |
|---|---|
| **User** | บัญชีผู้ใช้งานระบบ มีรหัสประจำตัว (ID), อีเมล (Email), รหัสผ่านที่เข้ารหัสแล้ว (Password Hash) และชื่อที่แสดง (Display Name) |
| **User Profile** | ข้อมูลเสริมส่วนบุคคลของผู้ใช้ ได้แก่ ชื่อจริง (First Name), นามสกุล (Last Name), เบอร์โทรศัพท์ (Phone), ที่อยู่ (Address) และเลขประจำตัวผู้เสียภาษี (Tax ID) |
| **Authentication** | กระบวนการยืนยันตัวตนด้วย Email และ Password คืนค่าเป็น JSON Web Token (JWT) เพื่อใช้เข้าถึง API ที่ต้องล็อกอิน |
| **Change Password** | ฟังก์ชันการเปลี่ยนรหัสผ่านของผู้ใช้ที่ล็อกอินอยู่ โดยต้องยืนยันด้วยรหัสผ่านเดิมก่อนทุกครั้ง |
| **Alert Card** | องค์ประกอบ UI สำหรับแจ้งเตือนผลการทำงานหรือข้อผิดพลาดบนแบบฟอร์ม มีดีไซน์โทนสีนุ่มนวลและไอคอนสื่อความหมาย |
| **Tax Record** | ข้อมูลบันทึกประวัติการคำนวณภาษีเงินได้บุคคลธรรมดาของผู้ใช้ในแต่ละครั้ง |
| **Responsive Layout** | การจัดโครงสร้างหน้าเว็บที่ปรับเปลี่ยนอัตโนมัติตามขนาดหน้าจอ (Desktop, Tablet, Mobile) เพื่อประสบการณ์ใช้งานที่ราบรื่น |
| **Mobile Drawer** | แถบเมนูนำทางด้านข้างสำหรับหน้าจอมือถือ ที่สามารถสไลด์เปิด-ปิดได้ด้วยปุ่ม Hamburger พร้อมพื้นหลังมืด (Backdrop Overlay) |
| **Breakpoint** | จุดตัดขนาดความกว้างหน้าจอสำหรับแยกเลย์เอาต์ (เช่น Desktop ≥ 1024px, Tablet 768px-1023px, Mobile < 768px, Small Mobile < 480px) |
| **Responsive Data Table** | ตารางแสดงผลข้อมูลที่รองรับการเลื่อนแนวนอน (Horizontal Scroll) หรือแปลงเป็นมุมมองการ์ด (Card View) บนอุปกรณ์พกพา |
| **Adaptive Card View** | รูปแบบการแสดงผลข้อมูลที่แปลงจากตารางแนวนอนมาเป็นกล่องการ์ดแนวตั้งบนหน้าจอขนาดเล็ก เพื่อให้อ่านง่ายและใช้งานสะดวก |
| **Quick-Jump Button** | ปุ่มลอยหรือแถบลัดสำหรับหน้าจอมือถือที่กดเพื่อเลื่อนหน้าจอ (Smooth Scroll) ไปยังส่วนแสดงผลลัพธ์ที่ต้องการได้ทันที |
| **Body Scroll Lock** | เทคนิคการล็อกการเลื่อนหน้าจอด้านหลัง (Disable Background Scrolling) ชั่วคราว ขณะที่เมนู Drawer หรือ Modal กำลังเปิดอยู่ เพื่อไม่ให้ฉากหลังเลื่อนตาม |
