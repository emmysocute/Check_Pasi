# พจนานุกรมคำศัพท์โดเมน (Domain Glossary)

| คำศัพท์ (Term) | ความหมายและบทบาทในระบบ (Definition & Responsibility) |
|---|---|
| **User** | บัญชีผู้ใช้งานระบบ มีรหัสประจำตัว (ID), อีเมล (Email), รหัสผ่านที่เข้ารหัสแล้ว (Password Hash) และชื่อที่แสดง (Display Name) |
| **User Profile** | ข้อมูลเสริมส่วนบุคคลของผู้ใช้ ได้แก่ ชื่อจริง (First Name), นามสกุล (Last Name), เบอร์โทรศัพท์ (Phone), ที่อยู่ (Address) และเลขประจำตัวผู้เสียภาษี (Tax ID) |
| **Authentication** | กระบวนการยืนยันตัวตนด้วย Email และ Password คืนค่าเป็น JSON Web Token (JWT) เพื่อใช้เข้าถึง API ที่ต้องล็อกอิน |
| **Change Password** | ฟังก์ชันการเปลี่ยนรหัสผ่านของผู้ใช้ที่ล็อกอินอยู่ โดยต้องยืนยันด้วยรหัสผ่านเดิมก่อนทุกครั้ง |
| **Alert Card** | องค์ประกอบ UI สำหรับแจ้งเตือนผลการทำงานหรือข้อผิดพลาดบนแบบฟอร์ม มีดีไซน์โทนสีนุ่มนวลและไอคอนสื่อความหมาย |
| **Tax Record** | ข้อมูลบันทึกประวัติการคำนวณภาษีเงินได้บุคคลธรรมดาของผู้ใช้ในแต่ละครั้ง |
| **Responsive Layout** | การจัดโครงสร้างหน้าเว็บที่ปรับเปลี่ยนอัตโนมัติตามขนาดหน้าจอ (Desktop, Tablet, Mobile) เพื่อประสบการณ์ใช้งานที่ราบรื่น |
| **Mobile Drawer** | แถบเมนูนำทางด้านข้างสำหรับหน้าจอมือถือ ที่สามารถสไลด์เปิด-ปิดได้ด้วยปุ่ม Hamburger พร้อมพื้นหลังมืด (Backdrop Overlay) |
| **Breakpoint** | จุดตัดขนาดความกว้างหน้าจอสำหรับแยกเลย์เอาต์ (เช่น Desktop ≥ 1024px, Tablet 768px-1023px, Mobile < 768px, Small Mobile < 480px) |
| **Responsive Data Table** | ตารางแสดงผลข้อมูลที่รองรับการเลื่อนแนวนอน (Horizontal Scroll) หรือแปลงเป็นมุมมองการ์ด (Card View) บนอุปกรณ์พกพา |
| **Adaptive Card View** | รูปแบบการแสดงผลข้อมูลที่แปลงจากตารางแนวนอนมาเป็นกล่องการ์ดแนวตั้งบนหน้าจอขนาดเล็ก เพื่อให้อ่านง่ายและใช้งานสะดวก |
| **Quick-Jump Button** | ปุ่มลอยหรือแถบลัดสำหรับหน้าจอมือถือที่กดเพื่อเลื่อนหน้าจอ (Smooth Scroll) ไปยังส่วนแสดงผลลัพธ์ที่ต้องการได้ทันที |
| **Body Scroll Lock** | เทคนิคการล็อกการเลื่อนหน้าจอด้านหลัง (Disable Background Scrolling) ชั่วคราว ขณะที่เมนู Drawer หรือ Modal กำลังเปิดอยู่ เพื่อไม่ให้ฉากหลังเลื่อนตาม |
| **Withholding Tax** | ภาษีเงินได้หัก ณ ที่จ่ายที่ผู้มีเงินได้ถูกหักสะสมไว้ระหว่างปีตามหนังสือรับรอง 50 ทวิ |
| **Tax Refund** | เงินคืนภาษีที่ผู้เสียภาษีมีสิทธิได้รับคืนจากสรรพากร เมื่อภาษีหัก ณ ที่จ่ายสะสมมากกว่าภาษีที่คำนวณได้จริง |
| **Additional Tax Payable** | ภาษีส่วนต่างที่ต้องชำระเพิ่มให้กรมสรรพากร เมื่อภาษีที่คำนวณได้จริงสูงกว่าภาษีหัก ณ ที่จ่ายสะสม |
| **Home Loan Interest** | ดอกเบี้ยเงินกู้ยืมเพื่อซื้อ เช่าซื้อ หรือสร้างอาคารที่อยู่อาศัย ลดหย่อนได้ตามจริงสูงสุดไม่เกิน 100,000 บาท |
| **Parent Allowance** | ค่าลดหย่อนอุปการะเลี้ยงดูบิดามารดาอายุตั้งแต่ 60 ปีขึ้นไปและมีรายได้ไม่เกิน 30,000 บาท/ปี ลดหย่อนคนละ 30,000 บาท |
| **Donation Allowance** | ค่าลดหย่อนเงินบริจาค (เพื่อการศึกษา/กีฬา/รพ.รัฐ 2 เท่า, บริจาคทั่วไปตามจริง) รวมกันไม่เกิน 10% ของเงินได้หลังหักลดหย่อน |
| **Flat Rate Tax Method** | การคำนวณภาษีวิธีที่ 2 (อัตราเหมา 0.5%) ตาม ม.48(2) สำหรับเงินได้ที่ไม่ใช่เงินเดือนรวมทั้งปีเกิน 120,000 บาท |
| **Tax Bracket Breakdown** | การแจกแจงรายละเอียดเงินได้และภาษีในแต่ละขั้นบันไดอัตราก้าวหน้า พร้อมระบุอัตราภาษีสูงสุด (Marginal Tax Bracket) |
| **Toast Notification** | การแจ้งเตือนสถานะผลลัพธ์แบบลอยชั่วคราว มีดีไซน์ทันสมัย ทดแทนการใช้ Browser alert() เดิม |
| **Parental Checkbox Selection** | การเลือกใช้สิทธิลดหย่อนบิดามารดาแบบรายบุคคล 4 รายการ (บิดาตนเอง, มารดาตนเอง, บิดาคู่สมรส, มารดาคู่สมรส คนละ 30,000 บาท สูงสุด 120,000 บาท) เพื่อความถูกต้องตามเงื่อนไขสรรพากร |
| **Dual-Rate Donation Persistence** | การจัดเก็บเงินบริจาคแบบแยกประเภท (การศึกษา/กีฬา/รพ.รัฐ 2 เท่า และทั่วไป 1 เท่า) ลงในฐานข้อมูล เพื่อให้สามารถกู้คืนข้อมูลเดิมได้สมบูรณ์ |
| **Shared Input Sanitization** | โมดูลกลางสำหรับตรวจสอบและคัดกรองตัวเลข ป้องกันเลขติดลบและตัวอักษรพิเศษที่ไม่ใช่ตัวเลข (Code Smell Refactoring) |
| **Monthly Income Tracker** | ระบบบันทึกรายได้ 12 เดือน (ม.ค. - ธ.ค.) สำหรับผู้ทำงานพาร์ทไทม์ ฟรีแลนซ์ หรือมีรายได้ผันผวน เพื่อสะสมยอดเงินได้ ภาษีหัก ณ ที่จ่าย และประกันสังคมตลอดทั้งปี |
| **Customizable Monthly Columns** | ฟังก์ชันการเลือกเปิด-ปิดคอลัมน์ข้อมูลในแต่ละเดือนได้เอง (รายได้, ภาษีหัก ณ ที่จ่าย, ประกันสังคม, โน้ต) เพื่อลดความซับซ้อนและให้เหมาะกับแต่ละบุคคล |
| **Part-time & Freelance Aggregator** | การรวมยอดข้อมูล 12 เดือน เพื่อส่งต่อไปยังระบบคำนวณภาษีประจำปี พร้อมประมาณการสิทธิเงินคืนภาษีสะสม (Estimated Tax Refund) |
| **Donation Ceiling Indicator** | ป้ายแสดงสิทธิลดหย่อนเงินบริจาคสูงสุดตามกฎหมาย (ไม่เกิน 10% ของเงินได้หลังหักค่าใช้จ่ายและค่าลดหย่อนอื่น ตาม ม.47(7)) แบบ Real-time พร้อมการแจ้งเตือนเชิงแนะนำ (Soft Warning) เมื่อผู้ใช้กรอกยอดเกินเพดาน |
