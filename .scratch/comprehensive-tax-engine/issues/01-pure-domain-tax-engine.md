# 01: Pure Domain Tax Engine Extraction

**What to build:** 
สกัดและแยกตรรกะการคำนวณภาษีเงินได้บุคคลธรรมดาทั้งหมดออกจาก React Component มาเป็นโมดูลฟังก์ชันบริสุทธิ์ (Pure Domain Module) รองรับการคำนวณรายได้ทั้งปี, ค่าใช้จ่ายเหมาจ่าย 50% ไม่เกิน 100,000 บาท, รวมค่าลดหย่อนพร้อมตรวจสอบเพดานตามกฎหมาย, เงินได้สุทธิ, อัตราก้าวหน้าขั้นบันได 8 ขั้น และอัตราภาษีสูงสุด (Marginal Rate) พร้อมชุด Automated Unit Tests ที่ครอบคลุมทุกกรณีขอบเขต (Edge Cases) เพื่อเป็นรากฐานที่มั่นคงก่อนขยายฟีเจอร์ภาษีอื่นๆ

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] แยกฟังก์ชันคำนวณภาษีออกมาเป็น Pure Function ที่ไม่มี Side Effects และไม่อิงกับ React Hooks
- [x] คำนวณรายได้ทั้งปีจากเงินเดือน x 12 และรายได้ฟรีแลนซ์/อื่นๆ อย่างถูกต้อง
- [x] คำนวณค่าใช้จ่ายเหมา 50% สูงสุดไม่เกิน 100,000 บาท
- [x] คำนวณค่าลดหย่อนพร้อมบังคับใช้เพดานกฎหมาย (ประกันชีวิต/สุขภาพ Cap 100,000 บ., ประกันสังคม Cap 9,000 บ., RMF 30% Cap 500,000 บ.)
- [x] คำนวณภาษีตามอัตราก้าวหน้า 8 ขั้น (0% ถึง 35%) ได้ผลลัพธ์ถูกต้องตรงตามเกณฑ์กรมสรรพากร 100%
- [x] ส่งคืนข้อมูลผลลัพธ์ที่สมบูรณ์: annualIncome, expenseDeduction, totalDeduction, netIncome, taxAmount, marginalRate, taxPerBracket
- [x] มีชุดทดสอบ Unit Test ตรวจสอบความถูกต้องของตรรกะการคำนวณและกรณีขอบเขต (Boundary Cases) ผ่านฉลุย
