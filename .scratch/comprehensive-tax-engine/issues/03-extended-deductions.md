# 03: Extended Deductions (Home Loan Interest, Parent Allowance, and Charitable Donations)

**What to build:** 
ขยายรายการลดหย่อนภาษีในระบบให้ครอบคลุมค่าลดหย่อนหลักของคนไทยตามเกณฑ์สรรพากร: เพิ่มช่องลดหย่อนดอกเบี้ยเงินกู้ยืมเพื่อซื้อที่อยู่อาศัย (สูงสุด 100,000 บาท), ค่าลดหย่อนอุปการะเลี้ยงดูบิดามารดา (คนละ 30,000 บาท), และเงินบริจาค (บริจาคการศึกษา/กีฬา/รพ.รัฐ หักได้ 2 เท่า และบริจาคทั่วไป รวมกันไม่เกิน 10% ของเงินได้หลังหักลดหย่อน) พร้อม Hint แนะนำเกณฑ์, Validation บล็อกเลขติดลบ, และขยายคอลัมน์ในฐานข้อมูล PostgreSQL ทันทีแบบ Vertical Slice

**Blocked by:** 01: Pure Domain Tax Engine Extraction

**Status:** closed

- [x] เพิ่มรายการลดหย่อน "ดอกเบี้ยเงินกู้ยืมเพื่อซื้อที่อยู่อาศัย" พร้อม Cap เพดานตามกฎหมายไม่เกิน 100,000 บาท
- [x] เพิ่มรายการลดหย่อน "ค่าอุปการะเลี้ยงดูบิดามารดา" สามารถเลือกจำนวนคนได้ และคำนวณคนละ 30,000 บาท
- [x] เพิ่มรายการลดหย่อน "เงินบริจาค" คำนวณสิทธิ 2 เท่าสำหรับการศึกษา/กีฬา/รพ.รัฐ และ 1 เท่าสำหรับทั่วไป โดย Cap ไม่เกิน 10% ของเงินได้หลังหักค่าใช้จ่ายและค่าลดหย่อน
- [x] แสดง Hint คำแนะนำเกณฑ์สรรพากรใต้รายการลดหย่อนแต่ละหมวดอย่างชัดเจน
- [x] เพิ่มคอลัมน์ `home_loan_interest`, `parent_allowance`, `donation` ใน PostgreSQL ผ่าน Auto-migration
- [x] ปรับปรุง API ให้รับค่าและจัดเก็บข้อมูลรายการลดหย่อนใหม่ลงฐานข้อมูล
- [x] ผลการคำนวณภาษีสะท้อนสิทธิลดหย่อนที่เพิ่มขึ้นอย่างแม่นยำ
