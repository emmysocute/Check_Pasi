# 02: Withholding Tax, Tax Refund/Payable Differentiation, and Modern Toast Notifications

**What to build:** 
ผู้ใช้งานสามารถระบุภาษีเงินได้หัก ณ ที่จ่ายสะสม (ตามหนังสือรับรอง 50 ทวิ) พร้อมระบบจัดรูปแบบตัวเลข (Comma Preview) และเห็นผลลัพธ์สุทธิแบบเรียลไทม์ โดยระบบจะจำแนกและไฮไลต์อย่างชัดเจน: หากภาษีหัก ณ ที่จ่ายมากกว่าภาษีทั้งปี จะแสดงกล่องสีเขียวสดใส "🎉 คุณจะได้รับเงินคืนภาษี (Tax Refund)" พร้อมระบุยอดเงินคืนอย่างชัดเจน หรือหากภาษีทั้งปีมากกว่าจะแสดงกล่อง "ภาษีที่ต้องชำระเพิ่มเติม" สีส้ม/แดง พร้อมทั้งเปลี่ยนการแจ้งเตือนบันทึกข้อมูลจาก Browser `alert()` เดิมเป็น Toast Notification UI ที่ทันสมัย และทำการเพิ่มคอลัมน์ `withholding_tax` ลงฐานข้อมูล PostgreSQL ทันทีแบบ Vertical Slice

**Blocked by:** 01: Pure Domain Tax Engine Extraction

**Status:** completed

- [x] เพิ่มช่องกรอก "ภาษีหัก ณ ที่จ่ายสะสม" ในแบบฟอร์มรายได้ พร้อมตัวแสดงผล Comma Preview และระบบบล็อกเลขติดลบ
- [x] คำนวณยอดผลต่างสุทธิระหว่างภาษีทั้งปีกับภาษีหัก ณ ที่จ่ายสะสม
- [x] แสดงการ์ดสรุปผลลัพธ์ใน ResultPanel แยกสีชัดเจน: สีเขียวเมื่อได้รับเงินคืนภาษี (Tax Refund) และสีส้ม/แดงเมื่อต้องชำระภาษีเพิ่มเติม
- [x] สร้างและติดตั้งระบบ Toast Notification Component ที่แสดงผลสวยงามมุมจอ พร้อม Auto-dismiss และปุ่มปิด แทนที่ `window.alert()`
- [x] เพิ่มคอลัมน์ `withholding_tax DECIMAL(12,2) DEFAULT 0` ใน PostgreSQL ผ่าน Auto-migration
- [x] ปรับปรุง API `POST /api/tax/calculate` และ `GET /api/tax/history` ให้บันทึกและส่งคืนฟิลด์ `withholding_tax`
- [x] ผู้ใช้สามารถบันทึกและดึงข้อมูลภาษีหัก ณ ที่จ่ายและสถานะเงินคืนภาษีกลับมาแสดงผลได้อย่างถูกต้อง
