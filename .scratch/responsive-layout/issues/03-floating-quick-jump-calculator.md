# 03: Floating Quick-Jump for Tax Calculator

**What to build:**
ผู้ใช้งานบนหน้าจอมือถือที่กำลังกรอกข้อมูลรายได้และค่าลดหย่อนในหน้า Tax Calculator สามารถตรวจสอบยอดภาษีประมาณการที่เปลี่ยนแปลงตามเวลาจริงได้จากแถบปุ่มลอย (Floating Quick-Jump Bar) ด้านล่างหน้าจอ และสามารถแตะปุ่มเพื่อเลื่อนหน้าจอ (Smooth Scroll) ตรงไปยังการ์ดผลลัพธ์ภาษี (`ResultPanel`) ได้ทันที โดยไม่ต้องปัดหน้าจอเองผ่านแบบฟอร์มที่มีความยาว

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] แสดงแถบปุ่มลอย (Floating Quick-Jump Bar) ที่ด้านล่างของหน้าจอเฉพาะบนอุปกรณ์มือถือ (< 768px)
- [x] ปุ่มลอยแสดงยอดภาษีที่ต้องชำระปัจจุบันที่คำนวณแบบ Real-time ตามข้อมูลในฟอร์ม
- [x] เมื่อแตะปุ่มลอย หน้าจอจะทำการ Smooth Scroll ไปยังส่วน ResultPanel อย่างแม่นยำ
- [x] ปุ่มลอยมีดีไซน์ทันสมัย โทนสีและเงาชัดเจน และไม่บดบังองค์ประกอบสำคัญของแบบฟอร์มจนเกินไป
- [x] บนหน้าจอ Desktop และหน้าจอกว้าง ปุ่มลอยถูกซ่อน และแสดง ResultPanel ในรูปแบบ Sticky Side Panel ตามปกติ
