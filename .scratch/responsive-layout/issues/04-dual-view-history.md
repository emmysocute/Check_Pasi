# 04: Dual-View Calculation History (Table & Cards)

**What to build:**
ผู้ใช้งานบนหน้าจอมือถือสามารถตรวจสอบประวัติการคำนวณภาษีย้อนหลังได้ผ่านมุมมอง Adaptive Card View ที่แสดงรายการประวัติแต่ละครั้งเป็นการ์ดแยกกล่อง มีข้อมูลวันที่, รายได้, ค่าลดหย่อน และยอดภาษีที่เน้นชัดเจน พร้อมปุ่มลบที่กดง่าย ขณะที่ผู้ใช้บนหน้าจอขนาดใหญ่ (Desktop/Tablet) ยังคงได้รับมุมมองตารางข้อมูลเต็มรูปแบบที่มีระบบเลื่อนแนวนอน (Horizontal Scroll) ป้องกันข้อความตกขอบ

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] บนหน้าจอ Desktop/Tablet (≥ 768px) แสดงผลประวัติในรูปแบบตารางข้อมูลที่มีแถบครอบเลื่อนแนวนอน (`overflow-x: auto`)
- [x] บนหน้าจอมือถือ (< 768px) ซ่อนมุมมองตาราง และแสดงผลเป็นรายการการ์ดเดี่ยว (Adaptive Card View)
- [x] การ์ดแต่ละใบแสดง วันที่คำนวณ, รายได้ทั้งปี, ค่าลดหย่อนรวม และภาษีที่ต้องชำระในรูปแบบที่อ่านง่าย
- [x] ปุ่มลบรายการประวัติในมุมมองการ์ดมีขนาดสัมผัสที่กดง่ายและปลอดภัยจาก Misclicks
- [x] เมื่อไม่มีข้อมูลประวัติ แสดงข้อความแจ้งเตือนที่จัดวางสวยงามในทุกขนาดหน้าจอ
