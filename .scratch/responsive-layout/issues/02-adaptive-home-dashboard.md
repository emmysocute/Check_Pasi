# 02: Adaptive Home Dashboard Layout

**What to build:**
ผู้ใช้งานบนหน้าจอมือถือและอุปกรณ์ขนาดเล็กสามารถดูข้อมูลสถิติภาษีล่าสุดและการแจกแจงสัดส่วนเงินได้ในหน้าหลัก (HomePage) ได้อย่างชัดเจน โดยการ์ดข้อมูลตัวเลขและกราฟวงกลม (PieChart) จะจัดเรียงในรูปแบบคอลัมน์เดี่ยวแนวตั้ง (Single Column Stack) แทนการบีบอัดเป็น 2 คอลัมน์ ทำให้อ่านตัวเลขและปฏิสัมพันธ์กับกราฟได้สะดวก

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] เลย์เอาต์แดชบอร์ดในหน้าหลัก (HomePage) แสดงผลแบบ 2 คอลัมน์บนหน้าจอ Desktop และปรับพับลงมาเป็น 1 คอลัมน์แนวตั้งบนหน้าจอมือถือ (< 768px)
- [x] กราฟวงกลม Recharts แสดงผลในสัดส่วนที่พอดีกับหน้าจอ ไม่ล้นและไม่ถูกตัดขอบ
- [x] ตัวเลขสรุปยอดภาษี รายได้ และค่าลดหย่อน แสดงผลชัดเจนในทุกขนาดหน้าจอ
- [x] ป้ายสถิติและ Welcome Banner ปรับระยะขอบและจัดวางองค์ประกอบให้สมดุลบนจอมือถือ
