# 01: Mobile Navigation Drawer and Compact Topbar

**What to build:** 
ผู้ใช้งานบนอุปกรณ์มือถือและแท็บเล็ตสามารถเข้าถึงเมนูนำทางของระบบ TaxMe ได้ผ่านปุ่ม Hamburger บนแถบ Topbar โดยเมนู Sidebar จะทำหน้าที่เป็น Off-Canvas Drawer ที่เลื่อนสไลด์ออกมาจากทางซ้ายพร้อมฉากหลังมืดโปร่งแสง (Backdrop Overlay) และสามารถปิดเมนูได้อัตโนมัติเมื่อเลือกหน้าใหม่ หรือกดปุ่มปิด (✕) หรือแตะฉากหลัง รวมถึงแถบ Topbar มีการย่อการแสดงผลข้อมูลผู้ใช้และซ่อนสโลแกนเพื่อไม่ให้เกิดการล้นจอแนวนอน

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] แสดงปุ่ม Hamburger Icon บน Topbar เฉพาะเมื่อขนาดหน้าจอต่ำกว่า 1024px
- [x] เมนู Sidebar เลื่อนสไลด์ซ่อน-แสดงแบบ Off-Canvas Drawer บนหน้าจอขนาดต่ำกว่า 1024px
- [x] แสดงฉากหลังมืดโปร่งแสง (Backdrop Overlay) เมื่อเปิด Drawer และแตะเพื่อปิดได้
- [x] มีปุ่มปิด (✕) ภายใน Drawer สำหรับกดปิดเมนูได้ด้วยตนเอง
- [x] เมนู Drawer ปิดตัวเองโดยอัตโนมัติเมื่อผู้ใช้คลิกลิงก์เปลี่ยนเส้นทาง (Route Change)
- [x] แถบ Topbar ซ่อนข้อความสโลแกนยาวบนหน้าจอมือถือ และย่อส่วนแสดงชื่อผู้ใช้ไม่ให้ล้นขอบจอ
- [x] บนหน้าจอ Desktop (≥ 1024px) เมนู Sidebar แสดงผลคงที่ถาวรทางซ้าย และปุ่ม Hamburger ถูกซ่อน
